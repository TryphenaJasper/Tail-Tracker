# Tail Tracker

Tail Tracker is a full-stack animal rescue and adoption platform that helps connect stray animals with people who can help.

## Features

- Animal adoption listings
- Rescue reporting for injured or sick animals
- Animal abuse reporting
- Location-based veterinary assistance
- Secure user authentication
- PostgreSQL database with Row Level Security

## Tech Stack

**Frontend:** React + Vite + CSS  
**Backend:** Node.js + Express.js  
**Database & Authentication:** Supabase + PostgreSQL  
**Images:** Cloudinary  
**Maps:** Mapbox / Google Maps

## Goal

To make animal rescue and adoption easier by connecting animals in need with people who can provide care, shelter, or immediate assistance.
